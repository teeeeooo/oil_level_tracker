# S11-R11 Detector Architecture Reset Validation

## Structural preservation gate

Before intentional R11 behavior changes, every extraction/removal commit must
prove:

- production has no import/dynamic-import path to retired legacy selectors;
- current candidate count, ordering, coordinates, scores and provenance remain
  unchanged on the four local videos;
- final tracking fingerprints and user-like Artifact replay remain unchanged;
- typed evidence compatibility reads both feature and penalty storage without
  changing values;
- current-frame/debug projection cannot become final authority; and
- debug-disabled detector time has no material regression.

Obsolete tests that assert superseded authority are removed or converted to a
production-cutover/absence contract. Safety, same-frame provenance, no-interface,
Foam independence and report contracts remain mandatory.

## Authority acceptance

Tests must exercise each anchor route separately and assert tier, primary reason
and failed gate. High material texture conflict must demote registered dynamic
material-path authority without deleting unrelated ordinary Oil. Semantic,
terminal or cross-representation routes cannot bypass an applicable
Foam/material-identity gate without an explicit independent reason.

## Bootstrap acceptance

Tests must prove:

- two late motion keyframes cannot promote a hundreds-frame prefix;
- seed membership is bounded to first/last keyframe plus the configured edge;
- excessive keyframe gaps split/reject a seed;
- minimum keyframe density, member count, span, direction and competition are
  all independently enforced;
- non-keyframe continuation remains continuation outside a bounded seed; and
- every published Oil row is an exact same-frame candidate.

## Foam material-track acceptance

Tests must distinguish:

- an eligible/confirmed Foam front and continuing residue edge from actual Oil;
- current Foam disappearance from material-track disappearance;
- a Foam-derived upper material row from a separately evidenced lower Oil row;
- a genuine thin Foam/Oil composition with independent lower-boundary evidence;
  and
- unrelated ordinary Oil from generic texture conflict.

The material track cannot publish Foam, Oil or state. It may only add typed
candidate opposition and reserve a bounded lower alternative.

## Replay and performance gate

Run focused authority/bootstrap/material-track tests, detector integration,
four-video replay, user-like Artifact replay, same-frame provenance and full
repository regression. Compare debug-disabled sample4 detector timing with the
R10 113-frame local reference of 7.062 s off and 7.182 s on. Python compile,
documentation links and `git diff --check` must pass.

The exact pushed R11 head then requires secure-Windows Base/Accum replay. Base
must not reproduce the 480–777.5 s lower-structure path. Accum must not reuse
the Y191–297 Foam/residue track as Oil when a visible lower interface exists.
Coverage alone is never a PASS.
