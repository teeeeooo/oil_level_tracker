# Completed Evidence

This directory preserves completed implementation, audit and validation records by milestone. Evidence files intentionally retain contemporaneous measurements, branch/PR identities and status/next-gate wording when that wording is part of the historical record.

Historical status or “next gate” prose inside an evidence file is **not current project authority**. Current milestone status and sequencing live only in [`../00-project/roadmap.md`](../00-project/roadmap.md) and [`../00-project/work-plan.md`](../00-project/work-plan.md). Durable contracts live in the relevant product/architecture/validation owner.

Evidence should normally remain semantically immutable. Taxonomy moves, classification notices and link repairs are allowed when they do not rewrite what the historical run or audit established.
