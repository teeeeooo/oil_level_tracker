Base HEAD: `dfe56af`, with pending structure-context Windows evidence/closeout.

## Selected hypothesis

Retain the vertical order and full observed height of raw-gray appearance within
each original candidate X strip. The completed context audit found no justified
simple artifact/static/texture veto. Prior finite-band controls already demonstrate
that a remote return can be outside every sampled O1 band while the complete
candidate witness and score remain unchanged. The additional observation is the
remote spatial transition itself, not a different weighting of existing scores.

The choice is provisional: private negatives are not established to exhibit a
return. A real Oil boundary plus a reflection and a bounded artifact may share a
profile; a broad structure and an Oil step may be identical. Human idx0/idx20
ambiguity is not overwritten by this experiment. Motion-only bootstrap, another
four-band profile score, coordinate priors and template retuning are not selected.

## Ownership search and implementation

Relevant source discovery covered the current witness extractor, row features,
material context, phase topology, registered temporal raster owner, packet/audit
projections and source-frame/mask helpers; repository-wide searches followed
responsibility names before introducing a module.

- `row_features.masked_row_mean` already owns masked row arithmetic; it is reused.
- `oil_phase_topology.dark_border_cap_conflict` emits a terminal-cap boolean;
  material context derives values from a different raster. Neither retains this
  ordered raw-gray strip observation.
- `temporal_raster_evidence` records aligned/exposure-adjusted change, already an
  existing motion signal. It is not independent identity or the selected spatial
  observation, and no new temporal route is added.
- `s11_shadow_target_audit` consumes stored records; it cannot reconstruct pixels
  beyond the packet. Extending it to assume wider appearance would be incorrect.
- New diagnostic module `tests/diagnostics/s11_spatial_context_probe.py` owns only
  a label-free `measure_context` function. It accepts explicit rasters, masks,
  exact source points and crop origin; returns ordered profile arrays/counts and
  unchanged point references. No decoding, candidate generation, selector, scores,
  decision thresholds or annotation system is added.

The probe preserves empty/masked rows as null despite the reusable arithmetic
helper's empty-row zero. Every row retains support counts and crop extent remains
censored. Same-X profiles are shared; points and basis remain explicit. The output
is always NOT_EVALUATED. Horizontal strip averaging remains a limitation rather
than a claimed full 2-D segmentation/topology measurement.

## Local verification

```bash
.venv/bin/python -m pytest -q \
  tests/unit/test_s11_spatial_context_probe.py \
  tests/unit/test_s11_target_aggregation_contract.py
```

**38 passed in 0.44 s**, including 19 new prototype controls. Four real O1 extractor
comparisons confirm equality of the complete original witness/fixed score despite
different remote image rows; new profiles distinguish those rows at both polarities
and two return extents. Auxiliary masks/material/static/Canny fixtures are fixed:
this is not equality of the full preprocessing pipeline on different images.

Counter-controls preserve mask/glare censoring, identical-image ambiguity,
stationary appearance, Oil-with-reflection possibilities and horizontal averaging
collisions. Equal image histograms with different vertical row order are retained
as different profiles. Nonzero source origin, shared intervals, zero versus
missing, sparse coverage, duplicate/invalid geometry and empty inventories are
also covered. No private candidate identity success is counted.

## Outcome and next boundary

The measurement can recover information lost by finite sampling in the constructed
controls. This is enough to specify a subsequent image/profile correspondence
probe, not to adopt an identity score. The real-data adapter is deliberately not
claimed as implemented: it needs existing bundle-link/packet/video/recipe/mask
owners, source-image verification, original candidate geometry, raster hashes and
immutable-input receipts. The [contract](../../20-architecture/s11-interface-observability-witness-architecture.md#w4-ordered-spatial-context--measurement-prototype)
defines that entry and stop conditions. There is no Windows CLI or new user data
request in this prototype. Broader filming, label changes and O3 integration are
not authorized by a synthetic information-gain result.
