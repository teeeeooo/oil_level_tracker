## Frozen mechanism and implementation

The [architecture](../../20-architecture/s11-interface-observability-witness-architecture.md#local-xy-oil-measurement-exclusion--proposed-contract)
freezes normalization, original support denominators, affected-only common-X
comparison and resource limits before outcomes. The explicit input uses existing
`Rect`, geometry fingerprints, assembler, material/raster-material generators,
phase scan and A1/native lineage. A small scope owner is necessary because the
existing recipe exclusions also change Foam/shared preprocessing, while artifact
templates reject whole candidates; neither owns Oil-only sample withdrawal.

The constructor is OFF by default. An immutable scope binds Glass, geometry,
settings, frame size and reference digest, includes its digest in runtime identity,
withdraws half-open XY samples and leaves same-X/other-Y usable. Shared pixels,
preprocessing, normalization/context, Foam and other proposal families remain
unchanged. Only contrast operations losing eligible samples use common columns;
remaining support and actually paired support are separately recorded. This does
not remove every upstream convolution/material dependency or certify identity.

Production code contains no sample/frame/Glass-specific branch. The diagnostic
runner explicitly freezes sample4 X[563,598), Y[816,828), 2 fps / 0–56 s, seven
existing positive and three existing wrong-target checkpoints. No parameter,
rectangle or alternate-mechanism sweep followed outcomes. The 420-pixel policy
is not a transfer of the 125 reviewed reference-edge labels. No UI/recipe schema,
ML, phase bypass, report repair or Windows run was introduced.
