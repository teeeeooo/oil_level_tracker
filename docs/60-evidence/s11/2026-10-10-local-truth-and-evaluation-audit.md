not an unquestionable physical oracle. Its 13 usable Oil coordinates comprise

Retain the original values and complete comparisons as historical scalar

## Adopted evaluation change and remaining work

The existing [13-case comparator](../../../tests/diagnostics/s11_resolver_replacement_compare.py)
fails any individual error increase above its numerical comparison epsilon,
even if aggregate error improves. That is an exact **legacy scalar agreement**
guard, not an uncertainty-aware proof of physical regression. Its implementation,
PASS/FAIL output and all existing tests are retained; this audit adds the missing
interpretation/eligibility boundary in the current validation owner.

The subsequent [output qualification](../../50-diagnostics/s11/2026-10-10-abc-source-interval-comparison.md#legacy-regression-output-now-states-its-actual-scope)
adds explicit legacy-agreement / physical-NOT_EVALUATED labels to the existing
JSON/CLI. It preserves the original computation, complete case list, guards,
PASS/FAIL and exit codes. The original audit's source pins and JSON remain
unchanged; this later tooling change is separately verified and attributed.

Future reports separate engineering compatibility, qualified physical positives,
unobservable/disputed controls, and legacy scalar agreement. No favorable subset
aggregate replaces the complete inventory. Any newly excluded/changed reference
is listed with a source-based reason before model selection. Known visible
positives still penalize missing observations. Uncertain truth cannot certify
prediction correctness or make all-abstain a success.

Local audit and source-role planning are complete. A future numeric dataset needs
a separately bound source/role/center/visibility/precision review; none is silently
created here. The base disagreement requires human adjudication only if that
claim is to become decisive truth again. It can remain unresolved while the
water-first qualitative development proceeds. No user re-answer or Windows run
is required to retain this quarantine or complete this audit.
