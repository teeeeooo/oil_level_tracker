# P5-S2 signed spatial conjunction feasibility

The [operation and one ablation](../../20-architecture/s11-interface-observability-witness-architecture.md#p5-s2-signed-spatial-conjunction--frozen-feasibility)
are frozen before real outcomes. The [preflight](2026-10-11-p5-spatial-conjunction/preflight.json)
pins 42 rasters and their prior source/role records; the
[runner](2026-10-11-p5-spatial-conjunction/run.py) reads saved arrays only.
This tests an appearance arrangement, with copied/warped structure retained as
an unresolved competing explanation. There is no production consumer or scalar
selection, and no claim that noncellular appearance means glass.

The helper extends `tests/diagnostics/s11_side_texture_probe.py`. Tests compare
the vectorized operation with an independent eight-pixel loop, verify shared
ablation support, polarity/copy invariance, hidden-pixel neutrality, input
immutability, missing support, no invented edges, small crops, type/resource
rejection and fixed-column handling. The new and existing side-texture suites
pass **27 tests**. The new model has not yet run on real controls at this freeze.

The 42 rasters comprise 18 existing public native/reduced graph controls,
14 sample4 default captures (all seven prior Foam frames and seven Oil
checkpoints), and all ten water support captures. This includes repeated views
of the same source and correlated native/reduced representations, not 42
independent scenes or a holdout. Only the original qualified intervals and
guide roles are used by the evaluator; no neighboring role/position labels are
created. The API receives gray/edges/visibility and a frozen column only.

The synthetic inventory includes stationary and inclined boundaries, polarity
reversal, identical printed copies, a deterministic row-wise optical warp and
its copy, missing/partial support and a uniform field. Comparison follows one
fixed radius, side scale rule, cost and margin. It ends in a continue/close
decision; no post-result parameter or model rescue is part of this trial.
