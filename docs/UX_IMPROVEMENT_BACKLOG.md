# Rotary Oil Level Tracker UX Improvement Backlog

## 목표

영상 편집 경험이 없는 일반 사용자가 시험 영상을 선택하고, 유면 관찰창과 기준점을 설정하고, 설정 점검 후 분석을 실행하는 흐름을 별도 설명 없이 완료할 수 있도록 Workbench를 단계적이고 복구 가능한 화면으로 개선한다.

## 전체 개선 제안

1. 기본 설정과 고급 설정 분리
2. ROI 집중 편집 모드
3. 작업 단계 안내
4. 하단 고정 실행 영역
5. 입력 필드별 즉시 오류 안내
6. 실행 취소와 다시 실행
7. 기준점 조정 확대 안내
8. 타원 크기 조절 중 실시간 크기 표시
9. 자동 저장과 비정상 종료 복구
10. Wizard와 Workbench 역할 분리

## Phase 1 구현 범위

### 1. 기본 설정 / 고급 설정 분리

기본 화면에는 일반 사용자가 자주 사용하는 항목만 표시한다.

- 관찰창 이름
- 분석 포함 여부
- 분석 시작 시 상태
- 판정 방식
- 기준점 안내 및 ROI 집중 편집 진입
- 검출 제외 영역

다음 항목은 고급 설정을 펼쳤을 때만 표시한다.

- 중심 X/Y와 너비/높이
- mm/pixel
- 테두리 제외 비율
- 검출기 세부 파라미터

내부 schema와 `.oilrecipe` 호환성은 유지한다.

### 2. ROI 집중 편집 모드

선택한 유면 관찰창을 별도 큰 대화상자에서 편집한다.

- 현재 영상 장면을 크게 표시
- 타원, 기준점, 제외 영역 편집
- 적용, 취소, 관찰창 초기화
- 취소 시 원본 설정을 변경하지 않음

`ROI 상세보기`는 검출 진단용, `ROI 집중 편집`은 사용자 설정용으로 역할을 분리한다.

### 3. 하단 고정 실행 영역

화면 하단에 항상 보이는 실행 영역을 제공한다.

- 현재 설정 상태와 오류 개수
- 설정 점검
- 프로필 저장
- 분석 실행

분석 실행은 가장 오른쪽의 주요 버튼으로 표시한다. 상단 toolbar에는 새 프로필, 열기, 결과, ROI 상세보기처럼 탐색성 기능만 남긴다.

### 4. 실행 취소 / 다시 실행 / 관찰창 초기화

다음 변경을 실행 취소 가능한 작업으로 기록한다.

- 타원 이동과 크기 변경
- 기준점 이동
- 제외 영역 추가, 삭제, 이동
- 우측 패널의 주요 설정 변경

단축키:

- 실행 취소: `Ctrl+Z`
- 다시 실행: `Ctrl+Y`

선택한 관찰창을 기본 geometry와 설정으로 되돌리는 초기화 기능을 제공한다.

### 5. 입력 필드별 즉시 오류 안내

설정 변경 후 validation을 즉시 다시 계산한다.

- 오류가 있는 입력에 빨간 테두리
- 경고가 있는 입력에 주황 테두리
- 해당 입력 아래 또는 인접 위치에 한국어 메시지 표시
- 하단 실행 영역에 전체 오류·경고 개수 표시
- 오류가 있으면 분석 실행 비활성화
- 설정 점검 결과를 클릭하면 해당 입력으로 이동

## Phase 1 완료 조건

- 기본 모드에서 고급 좌표와 detector 파라미터가 숨겨진다.
- 고급 설정을 펼치면 기존 설정을 모두 수정할 수 있다.
- ROI 집중 편집에서 적용 전까지 원본 profile이 변경되지 않는다.
- 취소는 편집 내용을 폐기하고 적용은 한 번의 undo 작업으로 기록된다.
- 타원, 기준점, 제외 영역, 주요 필드 변경을 undo/redo할 수 있다.
- 하단 실행 영역이 창 크기와 무관하게 항상 보인다.
- validation 오류가 입력 필드와 하단 상태에 즉시 반영된다.
- 기존 `.oilrecipe`를 정상적으로 불러오고 저장할 수 있다.
- 전체 pytest와 offscreen GUI regression test가 통과한다.
