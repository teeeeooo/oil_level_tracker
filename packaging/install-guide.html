Oil Level Tracker 설치 안내

이 ZIP에는 앱 폴더 OilLevelTracker와 이 안내가 들어 있습니다. 설치 프로그램 없이 폴더를 풀어 두고 실행합니다. 관리자 권한은 필요 없습니다.

필요한 것

  • Windows 10 또는 Windows 11 (64비트)
  • Microsoft Edge WebView2 런타임. Windows 11과 최신 Windows 10에는 이미 들어 있습니다.
  • 앱 폴더를 둘 공간 약 170 MB

설치하기

  1. 공유 폴더의 OilLevelTracker-.zip을 내 PC로 복사합니다(예: 다운로드 폴더). 공유 폴더에서 바로 풀거나 실행하지 않습니다.
  2. 복사한 ZIP을 마우스 오른쪽 단추로 누르고 모두 압축 풀기를 고릅니다.
  3. 풀 위치를 고릅니다. 내 PC의 로컬 디스크라면 어디든 됩니다(예: C:\Apps). 고른 위치에 OilLevelTracker 폴더와 이 안내가 생깁니다.

    피할 곳: 네트워크 드라이브, 그리고 OneDrive로 동기화되는 폴더입니다. 문서와 바탕 화면 폴더가 OneDrive로 동기화되는 PC가 많습니다.

  4. OilLevelTracker 폴더 안의 OilLevelTracker.exe를 두 번 누르면 앱이 열립니다.

    처음 실행할 때 "Windows의 PC 보호" 창이 뜰 수 있습니다. 서명하지 않은 부서용 프로그램이라 그렇습니다. 배포 담당자가 공유 폴더에 둔 파일이 맞으면 추가 정보를 누른 뒤 실행을 누릅니다.

  5. 바로 가기를 만들어 두면 편합니다(선택). OilLevelTracker.exe를 마우스 오른쪽 단추로 누르고 보내기 → 바탕 화면에 바로 가기 만들기를 고릅니다. Windows 11에서는 먼저 더 많은 옵션 표시를 누릅니다. 앱이 열려 있을 때 작업 표시줄의 앱 아이콘을 오른쪽 단추로 눌러 작업 표시줄에 고정해도 됩니다.

데이터가 저장되는 곳

Recipe와 검사문서\OilLevelTracker의 Recipes, Inspections 폴더
설정과 기록%LOCALAPPDATA%\OilLevelTracker (기록 파일 app.log)
앱 폴더아무것도 저장하지 않습니다.

그래서 앱 폴더를 지우거나 새 버전으로 바꿔도 Recipe와 검사는 그대로 남습니다.

새 버전으로 바꾸기

  1. 앱을 닫습니다.
  2. 예전 OilLevelTracker 폴더를 지웁니다. Recipe와 검사는 문서 폴더에 있어 지워지지 않습니다.
  3. 새 ZIP을 같은 위치에 풉니다(설치하기 1–3). 위치가 같으면 바로 가기를 그대로 쓸 수 있습니다.

지금 쓰는 버전은 앱의 도움말 창(F1) 아래에 "버전 "처럼 보입니다.

사용법

앱에서 F1을 누르고 사용 설명서를 누르면 사용 설명서가 브라우저로 열립니다. 지금 보려면 사용 설명서를 누릅니다(이 안내가 OilLevelTracker 폴더 옆에 있을 때 열립니다).

문제가 생기면

배포 담당자에게 알려 주세요. 다음을 함께 보내 주시면 원인을 찾기 쉽습니다.

  • 화면 캡처(Windows + Shift + S)
  • 앱 버전(도움말 창 아래)
  • 검사 이름과 무엇을 하던 중이었는지
  • 기록 파일 app.log: 탐색기 주소 표시줄에 %LOCALAPPDATA%\OilLevelTracker를 붙여 넣고 Enter를 누르면 이 파일이 있는 폴더가 열립니다.

에서 바뀐 것

첫 배포 버전입니다. 이 버전으로 할 수 있는 일:

  • Recipe: 영상에서 Glass 타원, 0선, 판정 규칙을 정해 저장합니다.
  • 분석: 영상을 한 번 훑어 Glass마다 맥락 이미지와 Oil 선 초안을 만듭니다.
  • 편집: 초안을 고칩니다. 범위로 지우기, 연필, 점 잇기, 잡아끌기, FULL·EMPTY, 판단 불가, 복사와 붙여넣기, 메모.
  • 판정과 제출: 판정을 확인하고 제출합니다. 제출한 버전은 잠기고, 고쳐서 다시 제출하면 다음 버전이 됩니다.
  • 보고서: 버전마다 HTML 보고서 하나. 브라우저에서 인쇄하면 PDF가 됩니다.
  • 원본 영상 창: 원본 영상을 큰 창에서 재생합니다.
  • 사용 설명서: 도움말 창에서 엽니다.

알려진 제한:

  • Recipe를 지우는 기능은 아직 없습니다.
  • 0선이 Glass 타원의 맨 위나 맨 아래에 있으면 끌어서 옮길 수 없습니다. 숫자를 입력해 옮깁니다.
